# 🌌 Dark_Glass – Rukovoditel Skin

A modern **glass-inspired dark skin** for **Rukovoditel**, combining layered surfaces, subtle transparency, soft blur, and refined highlights for a more polished interface.

Dark Glass is designed to enhance Rukovoditel's appearance while retaining its native functionality and respecting application-configured colors wherever possible.

## ✨ Features

- **Glass design** — layered dark surfaces, translucent panels, soft shadows, and rounded corners.
- **Consistent interface** — refined navigation, tables, forms, buttons, dropdowns, dialogs, and tooltips.
- **Responsive styling** — layouts and controls adapted for desktop and smaller screens.
- **Native color support** — designed to preserve administrator-defined icon, status, button, and chart colors.
- **Standalone skin** — no additional plugin is required for the visual theme.

## ⚙️ Installation
Download the Dark_Glass – Rukovoditel Skin archive from this repository.

Unzip the skin archive package.

Copy the resulting folder into the /css/skins/ directory of your Rukovoditel installation.
