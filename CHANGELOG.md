# Changelog

Notable changes to **Dark_Glass**, a glass-style skin for Rukovoditel.

## v1.5.3 — Reports & UI Refinements

- Expanded Dark Glass styling across WebDataRocks Pivot tables, dialogs, filters, aggregation menus, and calculated values.
- Unified Highcharts appearance across reports, dashboard widgets, and chart positions.
- Improved chart backgrounds, labels, legends, gridlines, tooltips, and export menus.
- Fixed Kanban column headers displaying light backgrounds when scrolling.
- Improved datepicker contrast, selected date ranges, and rounded corners.
- Refined table headers, sorting indicators, action buttons, and form controls.
- Improved visual consistency, spacing, and contrast throughout the interface.

## v1.5.2 – UI Improvements & Bug Fixes

- Improved Dark Glass styling across forms, buttons, progress bars, labels, and notifications.
- Redesigned Stages indicators (Triangle, Rectangle, Dot, Circle).
- Enhanced Form Configuration and Mind Map appearance.
- Fixed Mind Map fullscreen display.
- Improved radio buttons, accordions, icon picker, and input controls.
- Fixed text contrast and various visual inconsistencies.
- Improved overall UI consistency and compatibility with Rukovoditel 3.7.3.

## v1.5.1 — UI Refinements

- Polished navigation tabs, buttons, dropdowns, and modal windows.
- Fixed overlapping menus in record actions and report filters.
- Improved joined inputs, color pickers, and form controls.
- Refined hover states, spacing, and responsive details.

## v1.5.0 — Code Cleanup

- Reorganized and cleaned up the stylesheet without redesigning the skin.
- Removed redundant rules and outdated code.
- Preserved existing assets and administrator-defined colors.

## v1.4 — Navigation Overhaul

- Reworked the sidebar, including its collapsed layout and flyout menus.
- Improved the logo area, menu spacing, and active-item styling.
- Updated search controls, dropdowns, and selection fields.
- Refined the header, notifications, and glass surfaces.

## v1.3 — Layout Improvements

- Improved page layouts, panels, tables, and forms.
- Refined rounded corners, borders, and spacing throughout the interface.
- Improved the sidebar toggle and general navigation behavior.

## v1.2 — Glass Design Expansion

- Extended the glass look to dialogs, buttons, and common form elements.
- Added more consistent transparency, blur, and shadows.
- Improved the appearance of lists, tables, and dashboard elements.

## v1.1 — Visual Refresh

- Refined the dark palette and introduced a more consistent glass appearance.
- Updated the sidebar, page backgrounds, and navigation styling.
- Improved text contrast and interactive states.

## v1.0 — Initial Release

- First public version of the Dark_Glass skin for Rukovoditel.
- Introduced dark translucent panels, rounded controls, and subtle shadows.
- Established the core visual style used by later versions.
